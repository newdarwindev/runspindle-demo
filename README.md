# Runspindle demo

Technical and business editions cover the same proposition: run a recurring job with a stop or recovery path and an independently checkable result. The entry point uses a sticky local 50/50 edition split when available, honors GPC and Do Not Track, and defaults to the technical page if storage or secure randomness is blocked. Direct edition URLs are not assigned. There is no analytics, form, backend, or live operation.

Media are optional outbound links to the verified public branded fixture release. A fixture is not production qualification. The isolated Browser acceptance ledger is distinct from the suite's browser recordings and from recent CI.
